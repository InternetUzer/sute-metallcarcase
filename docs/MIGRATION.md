# Переход с Megagroup без преждевременного отключения

## Подготовка

Сохраните доступы и выгрузки старого сайта, записи DNS (A/AAAA/CNAME/MX/TXT, SPF/DKIM/DMARC), настройки почты и действующие документы. Изображения и тексты публичных страниц уже архивированы в репозитории; заявки и закрытые данные старого движка этим обходом не выгружались.

На REG.RU у домена были показаны NS Megagroup. Смена этих NS затрагивает всю DNS-зону, включая почту. Сначала подготовьте новую зону у выбранного DNS-провайдера со всеми необходимыми записями. Затем переключайте домен. Пока новая версия не проверена, не отключайте Megagroup.

## Адреса

Сохранены `/`, `/uslugi`, `/angary-i-sklady`, `/izgotovleniye-metallokonstruktsiy`, `/montaj-konstruktsii`, `/produkciya`, `/prays-list`, `/about`, `/kontakty`, `/sotrydnichestvo` и тематические страницы из `content.py: EXTRA`.

| Старый адрес | Результат |
|---|---|
| `/nashi-raboty` | 301 → `/produkciya` |
| `/ustanovka-konstruktsii` | 301 → `/montaj-konstruktsii` |
| `/zakazat`, `/napishite-nam` | 301 → `/request` |
| `/on-layn-zayavka` | 301 → `/sotrydnichestvo` (на старом сайте это сотрудничество) |
| `/regist` | 301 → `/login` |
| `/regist/agreement`, `/user/agreement` | 301 → `/privacy` |
| `/search` | 301 → `/uslugi` |

Новые посадочные: `/angary`, `/sklady`, `/betonnye-raboty`, `/montazh-sendvich-panelej`, `/o-kompanii`. 3D-каталог остаётся на старом `/prays-list`, поскольку этот адрес уже использовался для моделей.

Обход зафиксировал 27 публичных HTML-страниц; перед переключением дополнительно сравните URL с выгрузкой Яндекс Вебмастера/Search Console и журналом посещений. Обход не доказывает отсутствие других исторических адресов.

## Проверка до переключения

- Мобильная и настольная версия, кнопки, звонок, фотографии, фильтр, все 3D-модели.
- Заявка с файлом видна владельцу; письмо действительно приходит.
- Два тестовых клиента: каждый видит только свои документы; приглашение одноразовое.
- Телефон, email, реквизиты, фактическая география, политика и согласие проверены владельцем.
- HTTPS, резервная копия, восстановление, актуальные зависимости.

## Переключение

В `.env` установите `SITE_HOST=metalcarcase.ru`, `SITE_URL=https://metalcarcase.ru`, `TRUSTED_HOSTS=metalcarcase.ru,www.metalcarcase.ru`, `SITE_INDEXABLE=1`. При использовании www добавьте в Caddyfile отдельный блок для `www.metalcarcase.ru` с `redir https://metalcarcase.ru{uri} permanent`, направьте оба имени на VPS и пересоздайте контейнеры.

Перенесите DNS-зону и переключите NS/A только после готовности сервера и почты. Проверьте отсутствие старых AAAA-записей, ведущих на прежний сервер. Учитывайте срок обновления DNS; на это время сохраните старый сайт доступным. После переключения проверьте canonical, отсутствие случайного noindex и robots.txt, отправьте sitemap.xml в Яндекс Вебмастер и Google Search Console. Сохранение домена и адресов снижает риск потери переходов, но не гарантирует прежние позиции.

Отслеживайте 404, заявки, индексацию и скорость. Подключение аналитики выполняется с идентификаторами владельца и настройкой обработки данных. Городские страницы добавляйте только для фактических регионов с полезным содержанием, а не автоматически для всех городов в радиусе.
