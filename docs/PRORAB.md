# Журнал работ «Прораб+» в админке (`/admin/prorab`)

Рабочий стол на компьютере для приложения «Прораб+» (Android): те же объекты, что в телефоне. Доступен только владельцу (role = admin).

## Как устроено

- Данные журнала сайт **не хранит**. Браузер владельца читает и пишет папку объекта на Яндекс Диске — ту же, к которой объект подключён в телефоне (`<папка>/data/*.json`, формат 1 с версиями полей, как в `cloud/SyncCore.kt` приложения). Веб-версия — ещё одно устройство: пишет только свой файл `data/web-<id>.json`.
- Объединение правок — по полям: побеждает более поздняя правка поля. Удаление — пометка `deleted = 1`.
- Ключ Яндекс Диска хранится только в `localStorage` браузера владельца и уходит только на `cloud-api.yandex.net`. На сервер сайта он не отправляется.
- Документы объекта (папки, Word, Excel, свои файлы) — в `<папка объекта>/Документы` на том же Диске. Новые .docx/.xlsx собираются в браузере (`office.js`), правятся в Яндекс Документах (открываются в новой вкладке).

## Рабочий стол

Значки «Журнал работ», «Финансы», «Техника и бригады», «Документы» и содержимое папки «Документы»; окна (перетаскивание, размер, свернуть/развернуть/закрыть), панель задач, меню «Пуск», контекстные меню. На узком экране окна на весь экран.

- «Сделано»: работа и объём; техника — сколько заплатили (расход в финансах `rw:<работа>`, статья «Аренда техники»); люди — численность бригады на день (`бригада:день`).
- «Задача»: план; нужная техника — вызов `task:<задача>:<техника>`, в финансах ничего; напоминание на телефоне накануне в 18:00.
- Финансы: приход/расход; расходы по технике правятся только в «Сделано».

## Изменения сайта

- `app.py`: маршрут `GET /admin/prorab` (`protected(admin=True)`); для него одного CSP `connect-src` дополнен адресами Яндекс Диска (`PRORAB_CONNECT`). Остальные страницы не меняются. Новых таблиц и миграций нет.
- `templates/prorab.html` (без встроенных скриптов и стилей), ссылка в `templates/admin.html`.
- `static/prorab/`: `schema.js` (генерируется из Model.kt приложения: `web/tools/schema.py` в репозитории приложения), `sync.js`, `model.js`, `disk.js`, `office.js`, `app.js`, `prorab.css`. Нужны и в приложении, и в webroot/static.
- Необязательная настройка: `YANDEX_CLIENT_ID` (окружение) или `settings.prorab_client_id` — кнопка «Войти через Яндекс» (OAuth, Redirect URI = `https://metalcarcase.ru/admin/prorab`). Без неё вход по ключу с Полигона Яндекс Диска.

## Проверки

- `python -m pytest -q` (включая `tests/test_prorab.py`), `node --test tests/prorab/*.test.js`, `node --check static/prorab/*.js`.
- Ручная проверка на сайте: вход владельцем → «Журнал работ (Прораб+)» → ключ → папка объекта → «Сделано» с техникой и людьми → на телефоне синхронизировать объект → запись, расход и численность пришли; «Документы» → Word/Excel → открылись в Яндекс Документах.

## Совместимость с телефоном

Технику, бригады и работу техники телефон начинает передавать через облако в версии приложения после коммита `9dd2810` (TECHNADZOR). Более старые версии принимают журнал, задачи и финансы, а записи техники и бригад с сайта пропускают (ничего не ломается).
