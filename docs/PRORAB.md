# Журнал работ «Прораб+» (`/admin/prorab` и `/prorab`)

Рабочий стол на компьютере для приложения «Прораб+» (Android): те же объекты, что в телефоне.

## Вход

- Владелец: вход на сайт → «Панель управления» → «Журнал работ (Прораб+)» (`/admin/prorab`, role = admin).
- Те, с кем владелец поделился папкой «Прораб+» на Яндекс Диске (Диск → «Поделиться» → «Пригласить в папку», право «Редактирование»): `/prorab` без входа на сайт (noindex, `Disallow: /prorab`). Страница без данных: каждый входит **своим** Яндексом и видит только то, к чему у его аккаунта есть доступ на Диске. Если общая папка у человека называется иначе — меню «Прораб+» → «Папка рабочего стола».
- Затем вход в Яндекс Диск: кнопка «Войти через Яндекс» (OAuth, implicit flow; нужен `YANDEX_CLIENT_ID`, Redirect URI `https://metalcarcase.ru/prorab` и `https://metalcarcase.ru/admin/prorab`, права Яндекс Диска: `cloud_api:disk.read`, `cloud_api:disk.write`, `cloud_api:disk.info`) или ключ с Полигона Яндекс Диска.

## Как устроено

- Общий кабинет всех объектов. **Рабочий стол — папка «Прораб+» на Яндекс Диске владельца** (туда же телефон по умолчанию подключает объекты: `Прораб+/<объект>`). Папки с `data/` показываются значками объектов; всё, что создано на рабочем столе (ярлыки на сайты `.url`, папки, Word, Excel, загруженные файлы), лежит прямо в «Прораб+». Объект из другой папки Диска можно добавить вручную («Добавить объект из папки») — список хранится в браузере.
- Окно объекта — значки «Журнал работ», «Календарь», «Ведомость», «Финансы», «Техника и бригады», «Документы» (`<объект>/Документы`). Можно открыть несколько объектов сразу; у каждого своя загрузка, сохранение и обновление раз в минуту.
- Данные журнала сайт **не хранит**. Браузер читает и пишет папку объекта (`data/*.json`, формат 1 с версиями полей, как в `cloud/SyncCore.kt` приложения). Веб-версия — ещё одно устройство: пишет только свой файл `data/web-<id>.json`. Объединение правок — по полям: побеждает более поздняя правка поля; удаление — пометка `deleted = 1`.
- Настройки рабочего стола — `Прораб+/.prorab-desktop.json` (общие для всех компьютеров и приглашённых): фон и объекты из других папок Диска. Фон: готовые варианты или своя картинка (уменьшается до 2560 px, JPEG), картинка — `Прораб+/.prorab-desktop-*.jpg` (скрытые с рабочего стола), копия — в браузере. Показывается как `data:` (CSP `img-src 'self' data:` не меняется).
- «Новый объект» с компьютера: папка `Прораб+/<название>` и файл этого устройства; на телефоне — «Открыть из облака».
- Ключ Яндекс Диска хранится только в `localStorage` браузера владельца и уходит только на `cloud-api.yandex.net`; на сервер сайта не отправляется.
- Новые .docx/.xlsx собираются в браузере (`office.js`), правятся в Яндекс Документах (новая вкладка). Журнал за период выгружается в Excel (листы «По дням», «Итоги по дням», «Выполнено за период», «Объект») — скачать или сохранить в `<объект>/Документы/Отчёты`.

## Изменения сайта

- `app.py`: маршруты `GET /admin/prorab` (`protected(admin=True)`) и `GET /prorab` (без входа, noindex, `no-store`); только для них CSP `connect-src` дополнен адресами Яндекс Диска (`PRORAB_CONNECT`). `seo_panel.py`: `Disallow: /prorab` в robots.txt. Новых таблиц и миграций нет.
- `templates/prorab.html` (без встроенных скриптов и стилей), ссылка в `templates/admin.html`.
- `static/prorab/`: `schema.js` (генерируется из Model.kt приложения: `web/tools/schema.py` в репозитории приложения), `sync.js`, `model.js`, `disk.js`, `office.js`, `app.js`, `prorab.css`. Нужны и в приложении, и в webroot/static.
- Необязательная настройка: `YANDEX_CLIENT_ID` (окружение) или `settings.prorab_client_id` — кнопка «Войти через Яндекс» (OAuth, Redirect URI = `https://metalcarcase.ru/admin/prorab`). Без неё вход по ключу с Полигона Яндекс Диска.

## Проверки

- `python -m pytest -q` (включая `tests/test_prorab.py`), `node --test tests/prorab/*.test.js`, `node --check static/prorab/*.js`.
- Ручная проверка на сайте: вход владельцем → «Журнал работ (Прораб+)» → ключ → папка объекта → «Сделано» с техникой и людьми → на телефоне синхронизировать объект → запись, расход и численность пришли; «Документы» → Word/Excel → открылись в Яндекс Документах.

## Совместимость с телефоном

Технику, бригады и работу техники телефон начинает передавать через облако в версии приложения после коммита `9dd2810` (TECHNADZOR). Более старые версии принимают журнал, задачи и финансы, а записи техники и бригад с сайта пропускают (ничего не ломается).
