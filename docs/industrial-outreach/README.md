# Материалы для внедрения реестра промпарков

В этой папке лежат **исходные файлы исследования** для внутреннего раздела `/parks`.

## Файлы

1. [industrial_parks_prospecting_import.json](industrial_parks_prospecting_import.json) — реестр **117 парков-кандидатов** для загрузки администратором через форму `/parks/import`. Один парк = одна карточка. В файле нет результатов выездов и персональных контактов, собранных сотрудниками.
2. [industrial_parks_moscow_117_map_yandex_routes.html](industrial_parks_moscow_117_map_yandex_routes.html) — отдельная HTML-карта (Leaflet/OpenStreetMap) с фильтрами и переходами в Яндекс Карты. **Скачайте файл и откройте локально в браузере**: GitHub в интерфейсе просмотра исходников HTML не исполняет. Наличие этого файла не заменяет рабочую карту внутри сайта.

## Инструкция для кодера
- Реализованный модуль находится в ветке `codex/industrial-outreach-m7-20261102` и PR #23.
- Прежде чем импортировать файл, проверить актуальный код тестового сервера и авторизацию, интегрировать ветку в тестовую среду.
- Войти под администратором и загрузить JSON через `/parks/import`.
- Для остальных пользователей создать `field`-аккаунты в `/parks/staff` с привязкой к географической зоне.
- Проверить: вход, разграничение зон, карту, карточку парка, контакты и историю выездов, переход в Яндекс Карты.
- **Не загружать собранные сотрудниками контакты и заметки в публичный GitHub**. Эта папка должна содержать только исследовательский справочник.
- **Не выполнять деплой на production без отдельного согласования владельца**.

## Качество данных
Это **117 кандидатов**, а не 117 подтверждённых точных адресов в радиусе 50 км. В реестре есть объекты за пределами заданного радиуса, неточные координаты и действующие технопарки, не относящиеся к главному типу «М7 Купавна». Фильтр приоритета A отсеивает часть вторичных объектов.

Для поездок использовать кнопку «Найти парк по адресу», если точный въезд не подтверждён. Координатный маршрут в таком случае ведёт лишь к ориентиру.
